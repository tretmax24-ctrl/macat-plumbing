# MACAT Plumbing Services — Official Website

Professional, modern, interactive marketing website for **MACAT Plumbing Services** (Kampala, Uganda).

**Tagline:** *We fix today, so you can relax tomorrow.*

## Features

- Fully responsive (mobile-first)
- Dark modern theme with cyan/teal accents matching brand
- Hero section with branded graphics
- 6 service cards (General Plumbing, Leak Detection, Bathroom Installation, Drain Cleaning, Water Heater, Emergency)
- About section with real team/shop photo
- Why Choose Us + 4-step process
- Gallery
- Testimonials slider
- FAQ accordion
- Contact form that opens WhatsApp with pre-filled message
- Click-to-call + floating WhatsApp & Call buttons
- Smooth scroll, AOS animations, counter stats, preloader
- SEO-friendly meta tags

## How to Run Locally

Just open `index.html` in any modern browser, or serve with a local server:

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

Then visit `http://localhost:8000`

## Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Inter + Orbitron)
- Font Awesome 6
- AOS (Animate On Scroll)
